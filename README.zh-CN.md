<a id="关于咕咕"></a>

咕咕是桌面和 Android 客户端。你在自己的机器上跑 Claude Code、Codex 和其他 agent，和它们、和别的人一起，在共享的群和文件里干活。模型再聪明，也需要名字、长期上下文、工具和一台能跑的机器。这些都在咕咕里。[阅读更多理念](https://gugu.nextmind.space/zh/about.html)。

## 用起来是什么样

<a id="workspace-details"></a>

### 01 · 工作区

- **并排。** 对话、话题、文件、终端、浏览器和 App 并排放。可以分屏，也可以把标签拖成单独的窗口。
- **不打开也能看。** 鼠标悬停在输入框上方运行中的 agent 上，就能看到它最近的对话和进度。
- **对话界面或终端。** 用咕咕的对话界面，或者引擎自己的 TUI（在设置里打开 TUI 模式）。
- **分叉、改请求、旁聊。** 换条路试，不丢原来的；问个小问题，不碰当前任务。
- **导入历史。** 把其他 agent 的历史对话带进来继续。

<a id="files-details"></a>

### 02 · 文件与交付

- **同一份。** 每个群都有文件夹。Markdown、JSON 和文本文件是 [Yjs](https://github.com/yjs/yjs) 文档，人和 agent 同时改会自动合并，不会互相覆盖。
- **引用和选区。** 把文档的一段带行号送进输入框，或者把咕咕办公里的一块表格交给 agent。
- **版本。** agent 改过的 Office 文件、图片和 PDF 存成文件的下一个版本。

<a id="assistant-details"></a>

### 03 · 个人助理

- **你自己的咕咕。** 有名字、有性格的个人助理，记得你说过的话。
- **定时任务。** 让它或任何一个 agent 晚点做、按时做。
- **通讯录里的 agent。** 选好引擎、模型和机器，agent 就有了名字。第二天回来，接着同一个任务说。

### 04 · 模型与订阅

- **登录照常用。** Codex、Claude Code 的登录照常用，不花咕咕额度。Qwen Code、GitHub Copilot、OpenCode、Pi 等[接在同一层上](packages/session-plugins/src/agents/registry.ts)。
- **每个任务选模型。** 用自己的 API key，或者咕咕提供的模型。
- **用量与资源。** 七天用量、按任务看额度，资源监视器看正在跑什么。

<a id="teamwork-details"></a>

### 05 · Agent 协作

- **总负责、组长和执行者。** 总负责的 agent 把目标拆给组长和执行者，可以用不同引擎：Claude Code 带队，Codex 执行。侧栏画出这棵树。
- **找其中任何一个。** 树上每个 agent 都是真实的会话，可以打开直接说话。
- **两个人，两个团队。** 两个人各带自己的 agent 进同一个群，说好谁负责什么，再让两边的团队开工。任何一条消息都能分出话题，只有参与者收到通知。

<a id="tools-details"></a>

### 07 · MCP 与 Skills

- **资源库。** 提示词、agent、集成和 MCP 配置，按设备分开。
- **按对话选。** 每个对话选它能用哪些工具。
- **来自 App。** 装好的 App 自带工具和 Skills。

<a id="devices-details"></a>

### 08 · 设备与操作

- **你的机器。** 在手边的 macOS、Windows、Linux 电脑上跑，或者通过 SSH、远程隧道连接 Linux、macOS 机器。任务在你选的机器上跑，用的是那台机器的文件和程序。
- **Browser Use。** agent 在任务旁边的浏览器里操作。
- **Computer Use。** agent 操作桌面应用，窗口上有标签写明谁在控制，一键就能停。
- **你的手机。** Android 客户端可以查看、回复、审批别处跑着的任务。

# 为 AGI 打造的应用。

AGI 不会独自到来，它将以群体的形式到来。咕咕把你的 agent 和伙伴连在一起：共享上下文、接力干活、一起思考。

<a id="关于咕咕"></a>

咕咕是桌面和 Android 客户端。你在自己的机器上跑 Claude Code、Codex 和其他 agent，和它们、和别的人一起，在共享的群和文件里干活。[阅读更多理念](https://gugu.nextmind.space/zh/about.html)。
